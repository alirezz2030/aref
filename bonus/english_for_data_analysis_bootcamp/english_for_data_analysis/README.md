# English for Data Analysis Bootcamp

## Included files
- `english_for_data_analysis_bootcamp.ipynb` — 26 lessons; every lesson has a Markdown explanation and a Python phrase/practice cell.
- `data_analysis_english_glossary.csv` — 50+ terms with plain-English definitions and example sentences.
- `15_day_english_practice_plan.csv` — daily practice tasks.
- `README.md` — guide.

## Recommended method
For every lesson, read the explanation, run the cell, say the phrases out loud, and replace the example with details from one of your portfolio projects. Do not memorize phrases without understanding the metric or analysis behind them.

All examples are templates. Use real values and verified findings when discussing your own work.
