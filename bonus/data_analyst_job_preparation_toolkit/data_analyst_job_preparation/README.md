# Job Preparation Toolkit for Data Analysts

## Files
- `job_preparation_for_data_analysts.ipynb` — 26 lessons, each with Markdown and commented Python.
- `resume_template_data_analyst.md` — resume structure.
- `cover_letter_template.md` — concise cover letter.
- `business_case_interview_template.md` — framework for case interviews.
- `job_application_tracker_template.csv` — empty application tracker.

## Suggested workflow
1. Choose a target role and complete the skills evidence matrix in the notebook.
2. Update your resume using only truthful, provable evidence.
3. Publish two or three polished projects with READMEs and screenshots.
4. Practice SQL, Python/pandas, Power BI, statistics, and explaining business findings.
5. Log every application and next action.
6. Run mock interviews and improve the weakest areas each week.

All templates are starting points. Customize them to your real experience, location, role, and employer requirements. No template guarantees an interview or offer.
