# Personal Expense Tracker

A Python application for tracking and analyzing personal expenses.

## Features

- Add and view expenses
- Filter expenses by category
- Calculate total and average expenses
- Generate category-based reports
- Store data in an SQLite database
- Export expenses to CSV

## Technologies

- Python
- SQLite
- SQL
- CSV

## Requirements

Python 3.10 or newer.

This project uses Python's built-in libraries and does not require installing external packages for its core features.

## How to Run

1. Clone or download the project.
2. Open a terminal in the project directory.
3. Run:

```bash
python main.py
```

The SQLite database will be created automatically when the application initializes it.

## Learning Objectives

This project demonstrates Python functions, loops, conditional statements, exception handling, database operations, SQL queries, and CSV file processing.
